💡 Segredo Estratégico da FGV para Analista de Banco de Dados:
  • Português FGV nivela por baixo: A média dos aprovados em concursos da FGV em Português costuma girar entre 6 e 7 de 10. Dificilmente alguém faz 9 ou 10. Não se desespere em Português; garanta 6 a 7 acertos para não ser eliminado.
  • O diferencial real está no Módulo II (Específicas de BD): São 40 questões (66% da prova objetiva) e a Discursiva de 40 pontos versará 100% sobre esse conteúdo. Um candidato que acerta 35+ na objetiva de BD já tem bagagem para cravar 35+ na discursiva, saltando direto para o topo!
  • A Discursiva decide o 1º Lugar: Entre os 5 primeiros da objetiva, a diferença costuma ser de apenas 2 a 3 pontos. Uma discursiva nota 38 vs uma nota 30 inverte completamente a classificação final!

Hospedagem & Nuvem

Como Publicar no GitHub e Hospedar Grátis na Vercel

Gere um link público (ex: https://tjpb-simulado.vercel.app) para acessar seu simulador no celular, tablet ou compartilhar com outros colegas de estudo!

1

Subir no GitHub

O projeto já é um repositório Git local totalmente commitado. Para conectar à sua conta do GitHub:

# 1. Acesse github.com/new e crie um repo: "tjpb-simulado-bd"
git remote add origin https://github.com/SEU_USUARIO/tjpb-simulado-bd.git
git branch -M main
git push -u origin main

*Se preferir usar o GitHub CLI (`gh`), basta rodar: gh repo create tjpb-simulado-bd --public --source=. --push

2

Hospedar na Vercel (1 Clique)

O arquivo vercel.json já está gerado na pasta do projeto!

# Opção Rápida via Terminal:
npx vercel --prod
# Ou via Painel Web:
1. Acesse vercel.com e faça login
2. Clique em "Add New Project"
3. Importe o repo "tjpb-simulado-bd"
4. Clique em "Deploy" -> PRONTO!
✨ Seu link público com HTTPS automático estará online em segundos e atualiza sempre que você der git push!
